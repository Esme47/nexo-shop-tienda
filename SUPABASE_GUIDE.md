# Guía de Configuración de Supabase - NEXO Shop

Esta guía detalla los pasos necesarios para configurar tu base de datos Supabase para que la tienda de cursos funcione correctamente y de forma segura.

## 1. Estructura de las Tablas

Ejecuta estos comandos en el **SQL Editor** de tu panel de Supabase para crear o actualizar las tablas necesarias.

### Tabla `products` (Cursos)
Asegúrate de tener las siguientes columnas:
```sql
CREATE TABLE IF NOT EXISTS products (
  id int8 GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  title text NOT NULL,
  price numeric NOT NULL,
  original_price numeric,
  category text,
  image text,
  description text,
  created_at timestamptz DEFAULT now()
);
```

### Tabla `orders` (Inscripciones)
Esta tabla almacena los datos de los clientes y sus pedidos:
```sql
CREATE TABLE IF NOT EXISTS orders (
  id int8 GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  customer_name text NOT NULL,
  customer_phone text NOT NULL,
  customer_email text NOT NULL,
  customer_city text,
  total int8 NOT NULL,
  items jsonb NOT NULL,
  status text DEFAULT 'pending',
  created_at timestamptz DEFAULT now()
);
```

## 2. Seguridad (Row Level Security - RLS) 🛡️

El RLS es fundamental para proteger tus datos. Copia y pega estos comandos para configurar las políticas de acceso:

```sql
-- 1. Habilitar RLS en las tablas
ALTER TABLE products ENABLE ROW LEVEL SECURITY;
ALTER TABLE orders ENABLE ROW LEVEL SECURITY;

-- 2. POLÍTICAS PARA PRODUCTOS
-- Permitir que cualquier persona vea los cursos
CREATE POLICY "Permitir lectura pública de productos"
ON products FOR SELECT TO anon USING (true);

-- 3. POLÍTICAS PARA PEDIDOS (ORDERS)
-- Permitir que los clientes envíen su inscripción
CREATE POLICY "Permitir inserción pública de pedidos"
ON orders FOR INSERT TO anon WITH CHECK (true);

-- 4. POLÍTICAS PARA EL PANEL ADMIN (GESTIÓN)
-- IMPORTANTE: Para que el Panel Admin funcione, debe poder LEER y ACTUALIZAR.
-- La siguiente política permite que cualquier usuario con la "anon key" gestione pedidos.
CREATE POLICY "Permitir gestión de pedidos"
ON orders FOR ALL TO anon USING (true);
```

---

## 3. ⚠️ Advertencia de Seguridad Importante

La configuración actual utiliza una contraseña de administrador (`nexo2026admin`) guardada directamente en el código de la página (`index.html`).

**Riesgos:**
1.  **Visibilidad:** Cualquier persona que sepa "Ver código fuente" en su navegador puede encontrar la contraseña.
2.  **Privacidad:** La política "Permitir gestión de pedidos" en Supabase permite que usuarios técnicos puedan leer los datos personales de tus clientes (email, teléfono) si conocen la URL de tu proyecto.

**Recomendación Profesional:**
Para una seguridad real, se recomienda implementar **Supabase Auth**. Esto permitiría que solo tú, tras iniciar sesión con un correo y contraseña real, puedas ver y gestionar los pedidos, eliminando la necesidad de contraseñas inseguras en el código.
